# B2B-Positioning

Erarbeitet eine neue Positionierung oder analysiert eine bestehende, für B2B-Software und übertragbar auf andere Branchen.

Der Skill hat zwei Modi. Im ersten führt er Dich durch die Erarbeitung: historischen Ballast loslassen, Einzigartigkeit isolieren, den echten Wettbewerb kartieren, Value Mapping, ICP, Marktkategorie und Messaging nach Awareness. Im zweiten prüft er Website, Pitch-Deck oder Sales-Material auf Symptome schwacher Positionierung und gibt konkretes Feedback.

## Was Du bekommst

- **Positioning-Deck mit 6 Slides:** Functional Description, Problem Framing, Value Framing, drei Supporting Arguments
- **Positioning Map** aus Jobs-to-be-Done-Sicht: Alternativen, ihre Probleme und Deine Differenzierung gegenüber jeder einzelnen
- **ICP-Zusammenfassung** und **Messaging nach Awareness-Stufen** (Out-of-Market, In-Market, Shopping)
- im Analyse-Modus: Befund entlang von acht Prüfpunkten, von der funktionalen Beschreibung bis zum Awareness-Match
